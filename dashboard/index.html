    How the model works

    implied value = TVL × 0.30 × (1 + clamped 7-day growth × 0.60) × maturity

    • Base. TVL times 0.30: the value already locked is the anchor for what a launch would be worth.
    • Growth. The 7-day TVL change, clamped to −50% … +150%, weighted 0.60: momentum moves the value, but a single hot week cannot run away with it.
    • Maturity. 0.65 + 0.35 × min(age, 730 days) / 730: a protocol that has run longer with no token has more accrued launch value. Unknown age counts as 180 days.
    • Pre-token means what the snapshot records: no market cap, no CoinGecko id, no symbol. The page says a protocol “records no token”, never that it has none.
    • Kept out of the board: exchanges, versioned pools (names ending in V2, v2, 2.0 and the like), and wrapped, staked or bridged products — the watchlist’s own rule, applied to the early rows too.
    • Live tokens stay separate. Protocols that already trade are shown under Live tokens with the market’s own value (market cap), never mixed into the ranked board.

    Data: DefiLlama public protocols API, fetched once for this snapshot. The snapshot carries no ranking, no implied value and no farm plan — deriving them is this page’s work. No network is used: the whole dataset ships with the page.
